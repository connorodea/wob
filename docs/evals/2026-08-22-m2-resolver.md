# M2 Resolver Baseline Evaluation

- **Date**: 2026-08-22
- **Model**: `wob/resolver.py` v1 (deterministic rules R1–R6, no learned weights)
- **Dataset**: `tests/fixtures/matching/*.jsonl` — 24 hand-labeled pairs
  (exact 7 · compatible 4 · uncertain 4 · incompatible 9)
- **Method**: per-class precision / recall / F1 + abstention rate
  (`tests/test_resolver_eval.py`)

Abstention (uncertain) is a first-class output; nothing abstained silently.

## Notes

- R3 calibrated during this eval: differing ISBNs alone no longer imply
  "incompatible" (editions of a work share no ISBN); the resolver falls
  back to normalized title+author similarity bands.
- This is the baseline an embedding-based matcher must beat before it can
  replace any rule. The dataset is small; it grows with real listings.
- Known limitation: 24 pairs is a smoke-sized set — precision claims need
  the dataset at 100+ pairs before they become release-grade.
