# M2 Resolver Baseline Evaluation

- **Date**: 2026-08-22 (calibrated, third pass)
- **Model**: `wob/resolver.py` v1 (deterministic rules R1–R6, no learned weights)
- **Dataset**: `tests/fixtures/matching/*.jsonl` — 104 hand-labeled pairs
  (exact 23 · compatible 29 · uncertain 15 · incompatible 37)
- **Method**: per-class precision / recall / F1 + abstention rate
  (`tests/test_resolver_eval.py`)

## Calibration notes (what the labeled set forced)

- Titles keep subtitles: stripping at the first colon destroyed identifying
  words ("AI: A Modern Approach" collapsed to "artificial intelligence").
- Differing ISBNs alone are never "incompatible": editions of a work share
  no ISBN, so the resolver falls back to work identity (coverage + author).
- Distinctive-token matching: topical/generic words (machine, learning,
  linear, algebra, statistical, …) never drive compatibility alone; author
  overlap + near-identical titles absorb new-edition/subtitle changes;
  generic-only overlap between different authors is incompatible.

## Limitations

- 59 pairs is still small; target is 100+ before release-grade claims.
- Embeddings remain the fallback plan, not a replacement: any candidate
  model must beat this 1.0 baseline on the same set first.
